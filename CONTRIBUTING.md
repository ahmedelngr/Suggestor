# Contributing to Suggestor

1. Read [docs/README.md](docs/README.md) and your role file in [docs/roles/](docs/roles/).
2. Follow [docs/guardrails.md](docs/guardrails.md).
3. Follow [docs/workflow.md](docs/workflow.md): branch, small PR, 1 approval, squash merge.

Never commit secrets or phone numbers. Never push directly to `main`.
