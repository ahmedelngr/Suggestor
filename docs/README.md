# Suggestor docs: start here

Read in this order. It takes about 20 minutes.

1. [vision-and-scope.md](vision-and-scope.md): what we are building and what we are NOT building.
2. [architecture.md](architecture.md): how the pieces fit, with analogies.
3. Your role file in [roles/](roles/): what you own, what "done" means, your guardrails.
4. [guardrails.md](guardrails.md): rules everyone follows.
5. [workflow.md](workflow.md): how to get code into `main`.
6. [timeline.md](timeline.md): week-by-week plan (proposed).
7. [open-decisions.md](open-decisions.md) and [decision-log.md](decision-log.md): what is still undecided and what was decided.
